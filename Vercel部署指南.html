0准备工作

在开始之前，请确保你有以下三样东西：

  • 一个 GitHub 账号（免费注册：github.com/signup）
  • BinInsight 项目代码（在你的 D:\bininsight 目录里）
  • Git 工具（如果没装，去 git-scm.com 下载安装）

💡 为什么用 Vercel？

Vercel 是 Next.js 的官方托管平台，对 Next.js 项目有最好的支持。免费额度足够个人项目使用，全球 CDN 加速，推送代码自动部署。

1把代码推到 GitHub

Vercel 需要从 GitHub 拉取代码来构建。所以第一步是把本地项目上传到 GitHub 仓库。

1.1 在 GitHub 上创建新仓库

步骤 ①：新建仓库

登录 GitHub 后，点击右上角的 + → New repository

步骤 ②：填写仓库信息

  • Repository name：填 bininsight（或你喜欢的名字）
  • Description：可选，比如 "逆向工程与漏洞防护学习平台"
  • Public / Private：选 Public（免费版 Vercel 也支持 Private 仓库）
  • 不要勾选 "Initialize this repository with a README"
  • 点击 Create repository

1.2 本地初始化 Git 并推送

打开 PowerShell 或终端，进入项目目录：

# 进入项目目录 cd D:\bininsight # 初始化 Git 仓库（如果还没有） git init # 设置你的名字和邮箱（第一次用 Git 需要） git config user.name "你的名字" git config user.email "你的邮箱@example.com" # 添加所有文件 git add . # 提交 git commit -m "Initial commit" # 关联到 GitHub 仓库（把下面的地址换成你自己的） git branch -M main git remote add origin https://github.com/你的用户名/bininsight.git # 推送 git push -u origin main

⚠️ 注意

推送时会要求输入 GitHub 用户名和密码。注意：现在 GitHub 不支持密码登录了，需要用 Personal Access Token 代替密码。生成方法：GitHub 右上角头像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token，勾选 repo 权限后生成，复制这个 token 当密码用。

✅ 验证

推送成功后，刷新你的 GitHub 仓库页面，应该能看到所有代码文件了。

2注册 Vercel 并导入项目

步骤 ①：打开 Vercel 官网

访问 vercel.com，点击 Sign Up（注册）。

选择 "Continue with GitHub" 用 GitHub 账号直接登录，最方便。

步骤 ②：授权 GitHub

第一次登录会跳转到 GitHub 授权页面，点击 Authorize Vercel 允许 Vercel 访问你的仓库。

步骤 ③：导入仓库

登录后进入 Vercel 控制台，点击 Add New... → Project

在 "Import Git Repository" 列表中找到你的 bininsight 仓库，点击旁边的 Import 按钮。

💡 找不到仓库？

如果列表里没有你的仓库，点击 "Adjust GitHub App Permissions"，给 Vercel 授予对应仓库的访问权限。

3配置并部署

步骤 ①：配置项目设置

进入部署配置页面后，检查以下设置：

  • Project Name：自动填的 bininsight，不用改（你的网址会是 bininsight-xxx.vercel.app）
  • Framework Preset：应该自动识别为 Next.js，如果没有就手动选
  • Root Directory：保持 ./（因为代码就在仓库根目录）
  • Build and Output Settings：全部保持默认即可，Vercel 会自动用 next build
  • Environment Variables：我们的项目不需要环境变量，留空

步骤 ②：点击 Deploy

确认设置无误后，点击底部的 Deploy 按钮，开始部署。

步骤 ③：等待部署完成

部署过程大约 1-2 分钟，你会看到实时构建日志。等出现 "Congratulations!" 就成功了！

点击 Continue to Dashboard 进入项目面板。

🎉 恭喜！

你的网站已经上线了！地址在项目面板的 Domains 区域，格式类似 bininsight-git-main-xxx.vercel.app 或 bininsight.vercel.app。把这个链接发给任何人，他们都能访问你的网站。

4绑定自定义域名（可选）

如果你有自己的域名（比如 bininsight.cn），可以绑定到 Vercel 上，让网址更专业。

步骤 ①：在 Vercel 添加域名

项目面板 → Settings → Domains → 输入你的域名 → 点击 Add

步骤 ②：配置 DNS 解析

Vercel 会告诉你需要添加什么 DNS 记录。一般是：

  • 在你的域名服务商（阿里云/腾讯云/Cloudflare 等）的 DNS 管理里
  • 添加一条 CNAME 记录：主机记录填 www，记录值填 cname.vercel-dns.com
  • 或者添加 A 记录指向 Vercel 提供的 IP

步骤 ③：等待生效

DNS 解析生效需要几分钟到几小时。生效后 Vercel 会自动配置 HTTPS 证书（免费的）。

5后续：如何更新网站

部署完成后，更新网站非常简单——只要往 GitHub 推送代码，Vercel 会自动重新构建部署。

日常更新流程

# 1. 改完代码后，提交并推送 git add . git commit -m "更新了XXX内容" git push # 2. Vercel 会自动检测到 push，自动重新构建部署 # 3. 等 1-2 分钟，刷新网页就能看到更新了

💡 小技巧

在 Vercel 项目面板的 Deployments 标签里，可以看到每一次部署的记录和状态。每次 push 都会生成一条新记录，部署失败也能在这里看到错误日志。

?常见问题 FAQ

Q：Vercel 免费吗？有什么限制？

个人 Hobby 计划完全免费。限制是：每月 100GB 带宽、无限次部署、100GB 带宽/月。对于学习项目完全够用。如果超出了再考虑升级付费计划。

Q：部署失败了怎么办？

进入 Vercel 项目面板 → Deployments → 点击失败的部署 → 查看 Build Log。常见原因：代码有语法错误、依赖没装好、环境变量缺失。把错误信息复制出来排查。

Q：网站会被搜索引擎收录吗？

会的。Vercel 部署的网站和普通网站一样，可以被 Google、百度等搜索引擎收录。你也可以在项目里加 sitemap 和 robots.txt 来优化 SEO。

Q：能加评论功能或用户系统吗？

可以。评论功能推荐用 Giscus（基于 GitHub Discussions，免费）。用户系统可以用 Vercel 自家的 Auth.js 或第三方服务。我们的项目目前是纯静态的，加这些需要后端支持，但 Vercel 也提供 Serverless Functions。

Q：Git push 时提示 "fatal: remote origin already exists" 怎么办？

说明已经关联过远程仓库了。先用 git remote remove origin 删除旧的，再重新添加。

Q：可以在手机上访问吗？

可以！我们的网站做了响应式设计，手机、平板、电脑都能正常显示。
